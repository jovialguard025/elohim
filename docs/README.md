# Documentation (`docs/`)

1. **[Research Methodology](methodology.md)**: Theoretical formulation of confidence gating, uncertainty estimators, and decision thresholds.
2. **[Architecture](architecture.md)**: System design, multi-agent coordination, routing topology, and state transitions.
3. **[Experiment Protocol](experiment_protocol.md)**: Standardized test setups, benchmark dataset splits, baseline comparisons, and evaluation metrics.
4. **[Literature Review](literature_review.md)**: Survey of prior work in Multi-Agent Reasoning, Uncertainty Estimation, and Adaptive Routing.
5. **[Limitations](limitations.md)**: Known constraints, failure modes, computational overhead, and boundary conditions.
6. **[Final Report](final_report.md)**: Comprehensive summary of research findings, benchmark tables, and conclusions.
